# UML Design Projects

This repository contains UML diagrams created for different system design projects. The diagrams include activity diagrams, class diagrams, and use case diagrams.

Each project folder contains:

- `.drawio` files — editable source files created with draw.io
- `.pdf` files — exported versions for easy viewing and sharing

## Project Structure

### Advertisment Management System

- Activity Diagram
- Class Diagram
- Use Case Diagram

### Hospital Management System

- Activity Diagram
- Class Diagram
- Use Case Diagram

### Woorld Traveler

- Class Diagram
- Use Case Diagram

## How to View the Files

- Open `.pdf` files to view the diagrams directly.
- Open `.drawio` files in [draw.io](https://app.diagrams.net/) to edit the original diagrams.

## Tools Used

- draw.io / diagrams.net
- Unified Modeling Language (UML)
